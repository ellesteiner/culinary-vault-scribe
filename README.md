# My Cookbook

A personal recipe management app — import recipes from URLs or pasted text, generate new ones with AI from what's in your kitchen, cook hands-free with step-by-step Cook Mode, and keep a synced shopping list.

## Tech stack
- Vite + React + TypeScript
- shadcn-ui + Tailwind CSS
- Supabase (database, auth, edge functions)

## Local development
```sh
git clone <this repo's URL>
cd culinary-vault-scribe
npm i
npm run dev
```

## Deployment
Deployed on Vercel. See `vercel.json` for SPA routing config.
